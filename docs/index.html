What is OPC

一个人，做一支团队的事

OPC（One-Person Company，一人公司）：由一个创始人运营，通过技术、自动化工具、外包与 AI Agent 扩展能力，完成过去需要多人团队才能完成的商业活动。它不是「一个人硬扛所有事」， 而是把可复用的能力沉淀为可复用的资产。

一个人

创始人负责判断与决策，把执行交给系统。

AI 员工

研发、内容、研究、销售、运维等角色的 Agent。

自动化系统

工作流、CI、网关与 Agent 编排，稳定复用。

商业资产

产品、内容、模板、课程与用户数据。

四条业务线：内容生产（广告 / 课程 / 推广）· 软件开发（SaaS 订阅）· 服务咨询（自动化与 AI 员工落地）· 商业资产（模板 / Skill / 课程 / 代码库）。

Architecture

架构全景

五层结构：AI 员工 → 能力与数据 → 生产与自动化 → 获客与变现 → 基础环境，并由数据反馈闭环收口。高亮标注的是 EasyIndie 自研项目，其余为可替换的第三方工具。

Toolchain

工具选型

每一层都可以先用最小可行组合跑起来。标注为 高亮色 的是 EasyIndie 自研项目，负责把各层能力串成一套可运行的流程。

模块定位第三方工具 / 集成EasyIndie 自研
AI 员工数字员工 · 承担执行 Claude Code · Codex · OpenClaw · Hermes Agent EasyTeam · EasyProject
能力与数据模型 · 知识 · 存储 Claude / GPT / Gemini · Obsidian / Notion · NAS EasyAI
内容生产现金流引擎 HyperFrames · Runway · CapCut · Midjourney · ElevenLabs EasyContentCreator · EasyIndieSkill
自动运营规模化关键 n8n · Make EasyGithub
获客变现收入入口 Cloudflare · Vercel · Google Workspace / Zoho · Stripe / PayPal · Google Analytics / Plausible EasyGate
基础环境设备 · 网络 · 运维 Mac / PC · 防火墙 / VPN · GitHub / Docker EasyNet · EasyWork · EasyAndroid

工具均可替换。自研项目的价值在于把「模型 → 员工 → 生产 → 获客」串成一条自动化链路，而不是再封装一个工具。
